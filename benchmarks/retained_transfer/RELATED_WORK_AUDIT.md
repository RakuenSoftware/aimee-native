# Primary-source audit, in progress

Do not treat abstract-level checks as full mechanism audits.

- Qiu et al., *Phenomenal Yet Puzzling: Testing Inductive Reasoning Capabilities
  of Language Models with Hypothesis Refinement*, arXiv:2310.08559, ICLR 2024.
  https://arxiv.org/abs/2310.08559 . Inducing versus applying rules motivates the
  split; our construction is newly generated and is not the MiniSCAN benchmark.
- *Cache-to-Cache: Direct Semantic Communication Between Large Language Models*,
  arXiv:2510.03215, first 3 October 2025, ICLR 2026. Section 3.3.4 explicitly
  trains the C2C module while both language models are frozen.
  https://arxiv.org/html/2510.03215v2 . Compare explicit records regenerated by
  each receiver against transferred/fused donor KV, not against all transfer.
- The supplied ExpGraph identifier arXiv:2605.30712 is now titled *ExpHarness:
  Model-Agnostic Experience Learning through a Trainable Harness* in v2.
  https://arxiv.org/html/2605.30712v2 . The copilot is reinforcement-trained.
  Record the version-specific title and inspect v1 before citing ExpGraph.
- Li et al., *Frozen Memory Is Not Enough: Rethinking External Memory as
  Extraction*, arXiv:2608.17050, first 17 August 2026. Current v3 distinguishes
  trained target readers from compatible reader reuse without target training;
  do not claim every transfer requires additional target training. Source memory
  acquisition itself is trained. https://arxiv.org/html/2608.17050v3 .
- *Metis: Memory Foundation Model*, arXiv:2607.26760, first 29 July 2026.
  https://arxiv.org/abs/2607.26760 . Abstract describes memory-specific mid-training,
  then gradient-free updates. Full methods audit pending. This is distinct from
  the June paper *Metis: Bridging Text and Code Memory for Self-Evolving Agents*.
- *MoNe: Modular Neural Memory for Efficient Long Context Inference*,
  arXiv:2608.17616, first 18 August 2026. https://arxiv.org/abs/2608.17616 .
  Test-time fast-weight learning is not 'no additional training'; methods pending.
- *MemGen: Weaving Generative Latent Memory for Self-Evolving Agents*,
  arXiv:2509.24704, first 29 September 2025. https://arxiv.org/abs/2509.24704 .
  Trigger/weaver training requires a methods check before final comparison.
- MentorPulse, arXiv:2608.20927, first 21 August 2026; windowed refresh training
  versus training-free pilot must be distinguished. Full audit pending.
