Native-serving hosts can submit terminal contributions against immutable Aimee publication pins. Aimee performs bounded asynchronous semantic intake or an explicit literal integer contract, compiles private capability and resource bindings, and associates each contribution with one canonical action identity. The existing dispatcher enforces current memory/source authorization and independently observed effects; stale views, changed resources and duplicate dispatch are refused.

The model supplies semantic content or values. Tool implementation, OS details, authority and revision decisions remain with Aimee. This does not train tools into a model or grant authority to generated completion claims.
