# Corrective source-procedure fidelity diagnostic

Declared before its model calls; post-hoc selection of the known Requests-2193
failure. This does not revise the completed 32-task study.

Compare five conditions: original procedure natively, compact procedure
natively, original procedure as text, compact procedure as text, and no memory.
Use the exact six-message prefix before the failed first patch application.
Keep the original seed, temperature zero, 1,536-token response budget,
6,376-token input limit, and same final Q8 runtime image. No truncation is
permitted. Run once in that order and once in reverse. These deterministic
repeats are order checks, not independent replications.

The original record must retain its publication identity. The compact record
is a mechanical lossless representation of the same successful own patch,
validated on the original base. It contains no hidden reference solution.
Native conditions receive the full record through publication selection;
text conditions append the corresponding complete record to the shared system
message. Save every request, response, usage count and publication result.

Accept exactly one fenced command. Execute it in an isolated fresh benchmark
container, after replaying the two preserved pre-edit commands. Preserve tool
outcomes and the resulting Git diff. Primary outcome: byte-for-byte equality
to the existing successful own patch. Record parser rejection and execution
failures separately. A shorter or semantically correct alternative patch can
fail this exact-reproduction metric; this is not an official task solve score.
Do not count an absent or interrupted inference as failed model recall.

The operator queue waits for all candidate checks to finish, starts the stopped
study runtime, uses the upgraded FP32 resident compiler, and restores the
previous study preparation profile and stops the diagnostic server on exit.
No live experiment or candidate check shares these GPUs with the diagnostic.
Any follow-up full task grade or protocol change requires a separate record.
