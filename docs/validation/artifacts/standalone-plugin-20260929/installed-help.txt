Aimee Native installation and runtime launcher

Usage: aimee-native [OPTIONS] <COMMAND>

Commands:
  connect       Save the Aimee endpoint. Read a scoped access token from standard input
  memory-agent  Run the private host-side native selection broker
  fetch-memory  Fetch an approved complete native working set (control-plane diagnostic)
  install       Install a certified model/runtime from the configured release service
  run           Launch the installed native-memory runtime on loopback
  serve         Serve an existing model in the current vLLM environment with live Aimee
  rollback      Restore the preceding installed release; does not downgrade memory
  doctor        Show installation/hardware information without reading credentials
  help          Print this message or the help of the given subcommand(s)

Options:
      --root <ROOT>  
  -h, --help         Print help
  -V, --version      Print version
